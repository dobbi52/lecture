# 강의 슬라이드

GitHub Pages 주소: https://dobbi52.github.io/lecture/

## 구성
- `index.html` — 첫 화면(강의 목록)
- `lectures.js` — 강의 목록 데이터. 새 강의는 맨 위에 항목을 하나 추가
- `날짜-이름/` — 강의마다 폴더 하나 (`index.html`, `deck.css`, `assets/`)

## 슬라이드 조작
- → / 스페이스 / 클릭: 다음, ←: 이전
- F: 전체 화면, N: 발표자 노트 보기, P: 발표자 창(노트·타이머)을 따로 열기
- 주소 끝에 `#5`처럼 붙이면 5번째 장부터 시작
